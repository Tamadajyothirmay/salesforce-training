# Salesforce Platform Basics

## 1. What is Salesforce Platform?

Salesforce Platform is a cloud-based platform used to build and customize business applications.  
It helps companies manage customer relationships, automate business processes, store data, and create applications without managing servers or hardware.

Salesforce provides:
- CRM services
- Cloud storage
- Automation tools
- Security features
- App development tools

It supports both:
- Configuration (No-code)
- Custom Development (Coding)

---

## 2. Explain the Following

### App
An App in Salesforce is a collection of tools, tabs, and features designed for a specific business purpose.

Example:
- Sales App
- Service App
- Marketing App

Apps help users access related functionalities in one place.

---

### Object
An Object in Salesforce is used to store data.

It is similar to a table in a database.

Examples:
- Account
- Contact
- Opportunity

Objects contain records and fields.

Example:
Student Object may contain:
- Student Name
- Roll Number
- Branch

---

### Tab
A Tab is used to access objects, records, or applications in Salesforce.

Tabs help users easily open and manage data.

Example:
- Accounts Tab
- Contacts Tab
- Opportunities Tab

---

## 3. Difference: Configuration vs Coding

### Configuration (No-Code)

Configuration means customizing Salesforce using built-in tools without writing code.

Examples:
- Creating Objects
- Creating Fields
- Validation Rules
- Workflow Automation

Advantages:
- Faster development
- Easy to maintain
- No programming knowledge needed

---

### Coding (Apex Development)

Coding means developing custom functionality using programming languages like Apex and Lightning Web Components.

Examples:
- Complex business logic
- Custom integrations
- Custom UI development

Advantages:
- More flexibility
- Advanced customization
- Handles complex requirements

---

### Example: College Management System

#### App
College Management App

- Student Object

- Course Object

- Faculty updates attendance and marks.
- Students view course details and attendance.
